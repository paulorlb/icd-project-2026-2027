# ICD project: GOVCOPP publications (2020–2026)

This project reproduces an analysis of publications associated with GOVCOPP researchers. The W06 notebook checks the source files, builds a coauthorship network, and describes ties between formal groups. All paths start from the project root.

## Structure

```text
data/raw/                 local CSV copies, documented correction, and description
data/processed/           datasets generated by code
notebooks/W06S01_practice.ipynb
src/icd_project_aux/          reusable functions
outputs/w06/             results generated by the W06 notebook
```

Each future class notebook should write to its own subfolder under `outputs/`.

## Set up the environment

Open the project root in VS Code. In a terminal at that root, run:

```powershell
conda env create -f environment.yml
conda activate icd-project
python -m pip install -e .
python -c "import sys; print(sys.executable)"
python -c "from icd_project_aux.data import read_table; print(read_table.__module__)"
```

The `icd-project` environment installs the `icd_project_aux` helper package from `src/`.

If `environment.yml` changes, run `conda env update -f environment.yml --prune`. In VS Code, select the `icd-project` interpreter and notebook kernel. Check that `sys.executable` in the notebook points to the same environment.

## Run and verify

1. Open `notebooks/W06S01_practice.ipynb` with the `icd-project` kernel.
2. Use **Restart Kernel → Run All**. The notebook locates `environment.yml` from the working directory, checks the inputs and checkpoints, and writes the results.
3. Inspect `outputs/w06/coauthorship/`. Running the optional extension also creates `outputs/w06/coauthorship_min_weight_2/`. These files are generated; do not edit them by hand.

The original teacher solution is available in the course materials. This repository uses `notebooks/W06S01_practice.ipynb` as its single W06 notebook.

## Limits and decisions

- The 2026 records may be incomplete; the extraction date is unavailable.
- `publication_id` identifies publications. An authorship row represents one publication–researcher relationship. Joining the two tables increases row count; joined rows are not a count of publications.
- The W06 analysis does not alter the input CSV files. The one-off `R093` group correction is documented above; `data/processed/` and `outputs/` contain regenerable results. Git records code, documentation, and the notebook while excluding source data without documented redistribution rights, local environments, secrets, and generated results.

# Project records

This directory belongs to the student group. Keep analytical decisions and provenance close to
the code and analytical step that produced them.

- `research_plan_v0.md`: the question, units, data, strategy, expected outputs and risks.
- `evidence_register.md`: one row per claim, linked to the evidence that supports it.
- `contributions.csv`: who performed and checked each contribution.
- `ai_use_log.csv`: assistance requested, resulting change, independent check and decision.
- `git_github_guide.md`: beginner GitHub Desktop workflow for students.
- `git_github_teacher_setup.md`: canonical publication, group creation and update delivery for staff.

Do not place generated analytical tables or figures here. Those belong under `outputs/project/`.
